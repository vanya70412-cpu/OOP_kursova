# Project Task Management System (Система управління завданнями проєкту)

Програмний комплекс призначений для автоматизації процесів планування, обліку трудомісткості, фінансового аудиту та контролю виконання завдань програмного проєкту. Проєкт розроблено в межах курсової роботи (Варіант 20) з дисципліни «Об'єктно-орієнтоване програмування».

## Основний функціонал

* **Моделювання даних та сувора типізація**: Використання перелічуваних типів `TaskPriority` та `TaskStatus` на базі `Enum` і структур даних `@dataclass` (`Project`, `Employee`).

* **Інкапсуляція та захист інваріантів**: Захищені атрибути базового класу `Task` (`_task_id`, `_title`, `_base_hours`, `_priority`, `_status`) та специфічні параметри нащадків контролюються через властивості `@property` та `@setter` із генерацією винятків `ValueError` і `TypeError`.

* **Поліморфна ієрархія завдань**: Автоматичний розрахунок трудомісткості у методі `estimate_hours()` залежно від категорії завдання (`Task` -> `DevelopmentTask`, `BugTask`, `TestingTask`).

* **Магічні методи та індексація**: Розмежування користувацького (`__str__`) і технічного (`__repr__`) представлення, порівняння за пріоритетом (`__lt__`, `__eq__`), бізнес-математика об'єднання задач і додавання резерву часу (`__add__`), а також пошук завдання за унікальним ID або індексом (`__getitem__`, `__len__`).

* **Керування потоком даних та станом**:

  * **Функтор `TaskCostEstimator` (`__call__`)**: калькуляція вартості завдання з накопиченням загального бюджету проєкту та журналу розрахунків.

  * **Власний ітератор `PendingTaskIterator` (`__iter__`, `__next__`)**: фільтрація та обхід виключно невиконаних завдань у порядку спадання їхнього пріоритету.

  * **Ліниві генератори (`yield`)**: потокова вибірка прострочених завдань (`generate_overdue_tasks`) та завдань конкретного виконавця (`generate_tasks_by_assignee`) із константною складністю за пам'яттю `O(1)`.

  * **Контекстний менеджер `TaskStatusTransaction` (`with`)**: транзакційна зміна статусу завдання з контролем часового ліміту (`Time-Out`), автоматичним відкатом (`Rollback`) у разі помилки та логуванням у `history.log`.

* **Персистентність та звітування**: Збереження повного стану системи у бінарний файл `project_state.pkl` (`pickle`), зчитування лімітів із `config.json` (`json`) та експорт табличних звітів у формат `project_report.csv` (`csv`).

* **Стійкість до відмов (Fault Tolerance)**: Інтерактивне меню у файлі `main.py` на базі циклу `while True` та диспетчера `match/case` із захистом `try...except` та автозбереженням при виході.

## Вимоги до середовища

* Python версії 3.10 або новішої.

* Стандартна бібліотека Python (зовнішні залежності не потрібні).
